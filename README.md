# Blink Cross-Border Mentoring Programme Website

Website for the Blink Studios Cross-Border Mentoring Programme. It covers the programme, mentors, impact and stories, applications, partnership and sponsorship, resources, and the programme's policies.

## Stack

Static HTML, CSS and JavaScript with no build step. `globe.js` renders the interactive globe on the homepage.

## Run locally

Open `index.html` in any browser.

## Deploy

- **Quick preview:** drag the folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
- **Client hosting (Namecheap cPanel):** create a subdomain such as `programme.blinkstudios.co`, then upload the folder's contents with File Manager. Optionally password-protect the folder with Directory Privacy while it is in review.

Forms are front-end only in this build; submissions are not sent anywhere yet.
